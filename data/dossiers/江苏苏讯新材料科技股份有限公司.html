一、这是个什么生意

一句话： 把钢厂买来的热轧卷，加工成做易拉罐、啤酒盖、光缆保护层的金属薄板，卖给下游包装厂。

公司是干嘛的：

  • 做金属包装材料的研发、生产和销售【招股书 p.13】
  • 主要产品：镀铬薄板、镀锡薄板、不锈钢薄板、钢塑复合薄板【招股书 p.13】
  • 产品属于工业中间原材料，下游客户做食品饮料包装、化工产品包装、光纤光缆【招股书 p.14】

产品用在哪儿：

  • 镀铬薄板 → 皇冠盖、食品罐顶底盖、两片罐身、易开盖、旋盖、杂罐、啤酒桶顶底盖、化工桶、光纤光缆带金属屏蔽层【招股书 p.73】
  • 镀锡薄板 → 食品罐身料、食品罐顶底盖、杂罐、旋盖、易开盖、气雾罐、化工桶【招股书 p.74】
  • 不锈钢薄板 → 高端啤酒皇冠盖、高端食品旋开盖、精酿啤酒罐底盖、高端饮料罐顶底盖【招股书 p.74】
  • 钢塑复合薄板 → 啤酒桶顶底盖（食品级热覆膜铁）、通信光缆铠装（光纤光缆用钢塑复合带）【招股书 p.74-75】

钱怎么赚：

  • 买原材料（热轧卷、不锈钢）→ 自己加工（酸洗、冷轧、脱脂、退火、平整、拉矫、电镀铬/锡、覆膜）→ 卖给下游生产商和贸易商【招股书 p.76-77】
  • 销售模式：全部是买断式直销，客户分生产商和贸易商【招股书 p.77】
  • 贸易商占比：21.17%、20.71%、19.36%、18.54%，逐年下降【招股书 p.78】

老板是谁：

  • 实际控制人：李龙来、李康（李龙来之子）、黄雪亚（李龙来之妻），合计控制71.46%股份【招股书 p.13】
  • 李龙来任董事长兼总经理，初中学历，1989年开始养奶牛，2005年进入金属包装材料行业【招股书 p.33】

公司规模：

  • 2025年6月末总资产19.78亿元，股东权益10.72亿元【招股书 p.15】
  • 2024年营业收入29.82亿元，净利润2.18亿元【招股书 p.15】
  • 员工研发人员68人，占员工总数10.66%【招股书 p.19】

三、过去怎么走的，未来怎么说的

公司发展历程（四个阶段）：

1. 初创期（2009-2011） ：2009年4月成立，2010年1月生产线贯通。产品主要是镀铬薄板和光纤光缆用钢塑复合带。自主研发罩式退火大平整量提高硬度工艺，成为中粮包装等皇冠盖企业的材料供应商【招股书 p.80】

2. 全面提升期（2012-2016） ：购置东厂区土地，拿到首个发明专利，首次获得高新技术企业证书【招股书 p.80】

3. 快速发展期（2017-2020） ：购置南厂区土地，出口从零开始快速增长，建立员工持股平台【招股书 p.81】

4. 创新发展期（2021至今） ：产品线扩展到不锈钢薄板、食品级热覆膜铁、镀锡薄板。2025年3月新三板挂牌【招股书 p.81】

四、行业什么样

行业归属：

  • 属于"金属表面处理及热处理加工"（C3360）【招股书 p.13】
  • 产品用途是金属包装材料【招股书 p.89】

市场规模：

  • 2024年中国金属包装行业主营业务收入1,508.00亿元，占全国包装行业7.29%【招股书 p.93】
  • 2020年至2024年市场规模从1,083.26亿元增长到1,508.00亿元，年均复合增长率8.62%【招股书 p.93】
  • 规模以上企业（年营收2,000万元以上）从2020年734家增加到2024年984家【招股书 p.94】

公司在行业中的位置（按招股书原文照录）：

  • "根据中国包装联合会出具的证明，公司是国内首家规模化提供食品级不锈钢包装材料的厂家，2020年至2024年公司镀铬薄板产品的国内市场占有率连续五年排名第一，2022年至2024年公司啤酒罐用覆膜薄钢带产品的市场占有率连续三年排名第一"【招股书 p.14】
  • 2024年公司按主营业务收入计算的国内市场占有率约为1.86%，按利润总额计算的国内市场占有率约为3.44%【招股书 p.93】

出口市场占有率（公司自己测算）：

  • 镀铬薄板出口市占率：2022年31.26%、2023年34.32%、2024年35.68%、2025年1-6月27.94%【招股书 p.94】
  • 镀锡薄板出口市占率：2023年0.54%、2024年4.30%、2025年1-6月6.59%【招股书 p.95】

上游：

  • 热轧卷供应商集中度高：前五大供应商采购占比75.48%、71.55%、71.79%、69.93%【招股书 p.6】
  • 供应商都是大型钢厂：新金钢铁、上海宝钢、山东首钢、河钢集团等【招股书 p.112-113】
  • 上游钢厂强势，通常"全款发货"【招股书 p.98】

下游：

  • 食品饮料包装、化工产品包装、光纤光缆【招股书 p.14】
  • 客户包括青岛啤酒、雪花啤酒、燕京啤酒、百威、喜力、嘉士伯、可口可乐等品牌【招股书 p.14】
  • 前五大客户占比：29.93%、24.13%、22.91%、23.38%【招股书 p.108-109】

行业竞争格局（招股书原文）：

  • "目前行业已形成以大型国企、跨国企业和优质民企为核心的头部企业梯队"【招股书 p.103】
  • 头部企业有规模效应和资金优势【招股书 p.103】
  • 中小企业靠差异化策略争夺细分市场【招股书 p.103】

行业壁垒（招股书列了四个）：

1. 客户资源壁垒：头部品牌商不轻易换供应商【招股书 p.98】

2. 资金壁垒：设备贵、上游要全款、需要大量流动资金【招股书 p.98】

3. 技术与管理壁垒：多工序精密协作，需要长期经验积累【招股书 p.98】

4. 规模化与成本控制壁垒：规模大才能摊薄固定成本【招股书 p.98-99】

行业趋势（招股书说的）：

  • 绿色环保和循环利用深化【招股书 p.92】
  • 功能化和复合材料创新【招股书 p.92】
  • 下游需求驱动定制化发展【招股书 p.93】

行业挑战（招股书说的）：

  • 原材料价格波动压力【招股书 p.96-97】
  • 国际市场需求波动【招股书 p.97】

五、生意里的数字反差

1. 毛利率大起大落

  • 2022年毛利率17.24%，2023年直接掉到10.51%，降了6.73个百分点【招股书 p.6】
  • 2024年11.29%，2025年上半年13.77%，缓慢回升但没回到2022年水平【招股书 p.6】
  • 同期热轧卷采购均价从4,024.35元/吨降到3,606.46元/吨再降到3,281.14元/吨【招股书 p.110】
  • 原材料降价了，毛利率反而降了，说明产品售价降得比原材料快

2. 收入增长但利润缩水

  • 2022年收入22.39亿元，净利润2.69亿元【招股书 p.15】
  • 2023年收入24.15亿元（增长7.9%），净利润1.46亿元（下降45.7%）【招股书 p.15】
  • 2024年收入29.82亿元（增长23.5%），净利润2.18亿元（增长49.3%）【招股书 p.15】
  • 收入涨了，利润不一定跟着涨

3. 镀锡薄板从零到第二大产品只用了两年

  • 2022年镀锡薄板收入为0【招股书 p.76】

4. 境外收入占比波动剧烈

  • 2022年47.80% → 2023年31.14% → 2024年44.12% → 2025年上半年51.99%【招股书 p.6】

5. 产能利用率与产销率反差

  • 镀铬薄板、镀锡薄板、钢塑复合薄板产能利用率高达97.19%【招股书 p.106】
  • 但镀锡薄板2023年产销率只有90.04%【招股书 p.107】
  • 不锈钢薄板产能利用率从36.81%逐年升到76.37%，但2024年产销率只有83.33%【招股书 p.106-107】
  • 产能紧张和卖不动同时存在

6. 研发投入占比逐年下降

  • 2022年1.39% → 2023年1.60% → 2024年1.42% → 2025年上半年1.19%【招股书 p.15】
  • 收入从22.39亿涨到29.82亿，研发占比反而降了【招股书 p.15】

7. 前五大供应商占比近七成

  • 前五大供应商采购占比：75.48%、71.55%、71.79%、69.93%【招股书 p.6】
  • 全部是热轧卷供应商【招股书 p.6】
  • 第一大供应商新金钢铁2025年上半年占采购总额31.39%【招股书 p.112】

8. 存货持续增加

  • 存货账面价值：28,957.96万元 → 42,966.03万元 → 38,753.34万元 → 46,343.88万元【招股书 p.7】
  • 占流动资产比例从35.32%升到38.88%【招股书 p.7】

9. 子公司亏损

  • 苏讯钢丝（镀锌钢丝）：2024年净利润-826.26万元，2025年上半年-384.56万元【招股书 p.41】
  • 苏瑞精密（软水处理）：2024年净利润-24.14万元【招股书 p.40-41】
  • 苏弘新材（出租场地设备）：2024年净利润-36.89万元【招股书 p.41】
  • 赚钱的主要靠母公司主体和睿讯包装（2024年净利润240.73万元）【招股书 p.42】

六、值得关注的点 + 待核清单

值得关注的点

1. 毛利率为什么2023年突然崩了

  • 从17.24%掉到10.51%，掉了6.73个百分点【招股书 p.6】
  • 原材料价格同期也在降【招股书 p.110】
  • 需要搞清楚是产品售价降太快，还是成本没跟上，还是产品结构变了

2. 镀锡薄板的增长可持续性

  • 2023年产销率只有90.04%【招股书 p.107】
  • 这个新产品是抢了别人的份额，还是市场本身在涨

3. 境外收入占比超过一半

  • 2025年上半年境外收入占51.99%【招股书 p.6】
  • 主要出口土耳其、瑞士、阿联酋、菲律宾、南非【招股书 p.6】
  • 汇率波动直接影响利润：2024年汇兑损失1,669.63万元【招股书 p.6】
  • 2025年7月和8月刚在新加坡和马来西亚设立子公司【招股书 p.42-43】

4. 供应商集中度极高

  • 前五大供应商占采购总额约70%【招股书 p.6】
  • 第一大供应商新金钢铁占31.39%【招股书 p.112】
  • 公司说是因为热轧卷生产商本身集中度高【招股书 p.6】

5. 产能利用率接近饱和

  • 三类主要产品产能利用率97.19%【招股书 p.106】
  • 募投项目要扩产【招股书 p.24】
  • 但2023年镀锡薄板产销率只有90.04%【招股书 p.107】
  • 扩产之后能不能消化
  • 李龙来、李康、黄雪亚合计控制71.46%【招股书 p.13】
  • 处于绝对控股地位【招股书 p.7】
  • 公司自己把"实际控制人不当控制风险"列为法律风险第一条【招股书 p.7】

7. 历史上有股权代持和特殊投资条款

  • 2017年存在代持，已解除【招股书 p.35-36】
  • 与外部投资机构签过对赌条款，已终止但部分有恢复条件【招股书 p.38-40】
