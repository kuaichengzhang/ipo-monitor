一、这是个什么生意

一句话：卖服务器，主要是AI服务器，顺带卖点软件和充电桩。

  • 公司2021年9月13日成立【招股书 p.21】，2021年8月由超聚能作为专门主体收购超聚变有限100%股权，交易对价参考评估结果确定为570亿元【招股书 p.48】。
  • 主业是算力业务：数据中心服务器（AI服务器 + 通用计算服务器）、AI解决方案与操作系统、边缘计算及部件产品【招股书 p.104】。
  • 2026年1-6月，算力业务收入3,711,529.90万元，占主营业务收入99.63%【招股书 p.119】。其中数据中心服务器3,618,431.95万元，占97.13%【招股书 p.119】。
  • 数据中心服务器里，AI服务器1,985,214.46万元（占53.29%），通用计算服务器1,633,217.49万元（占43.84%）【招股书 p.119】。
  • 新兴业务（智企生态、能源智慧解决方案）2026年1-6月合计13,883.01万元，占0.37%【招股书 p.119】。
  • 生产模式：2023年至2025年主要靠外协工厂，2026年起逐步自建产线，形成"外协加工+自主生产"【招股书 p.23】【招股书 p.120】。
  • 销售模式：直销为主，2026年1-6月直销占78.35%，经销占21.65%【招股书 p.121】。
  • 员工4,286人（2026年6月末），其中研发1,449人，占33.81%【招股书 p.100】。
  • 控股股东超聚能持股31.3777%，实际控制人河南省国资委【招股书 p.21】【招股书 p.74】。

二、赚不赚钱

  • 营业收入：2023年2,509,191.59万元 → 2024年4,426,715.75万元 → 2025年5,824,616.34万元 → 2026年1-6月3,728,589.72万元【招股书 p.35】。
  • 净利润：2023年50,668.66万元 → 2024年72,191.42万元 → 2025年103,002.40万元 → 2026年1-6月210,769.53万元【招股书 p.35】。
  • 扣非归母净利润：2023年16,414.04万元 → 2024年64,796.89万元 → 2025年97,379.10万元 → 2026年1-6月214,376.52万元【招股书 p.36】。
  • 主营业务毛利率：2023年14.27% → 2024年10.04% → 2025年8.58% → 2026年1-6月15.49%【招股书 p.18】。2023至2025年持续下降，公司说主要受互联网客户收入占比提升影响【招股书 p.18】。
  • 直接材料成本占主营业务成本比例在95%以上【招股书 p.20】。
  • 关键原材料（模组、CPU、GPU、内存及存储）采购金额占生产物料采购总额比例：2023年77.65% → 2024年88.74% → 2025年86.59% → 2026年1-6月88.82%【招股书 p.20】。
  • 研发投入占营业收入比例：2023年4.90% → 2024年2.48% → 2025年2.02% → 2026年1-6月3.37%【招股书 p.36】。
  • 加权平均净资产收益率：2023年6.54% → 2024年8.20% → 2025年10.25% → 2026年1-6月13.52%【招股书 p.36】。
  • 资产负债率（合并）：2023年末71.87% → 2024年末77.87% → 2025年末67.06% → 2026年6月末76.97%【招股书 p.35】。

三、过去怎么走的，未来怎么说的

  • 主营业务收入结构里，AI服务器占比：2023年25.03% → 2024年50.87% → 2025年50.91% → 2026年1-6月53.29%【招股书 p.119】。
  • 通用计算服务器占比：2023年70.39% → 2024年45.56% → 2025年45.26% → 2026年1-6月43.84%【招股书 p.119】。
  • 2023年度至2025年度营收复合增长率52.36%【招股书 p.34】。
  • 境外营业收入：2023年261,676.44万元（占10.43%）→ 2024年431,285.87万元（占9.74%）→ 2025年754,394.96万元（占12.95%）→ 2026年1-6月505,431.45万元（占13.56%）【招股书 p.20】。
  • 员工人数：2023年末3,200人 → 2024年末3,328人 → 2025年末3,712人 → 2026年6月末4,286人【招股书 p.100】。
  • 募集资金投资项目：新一代算力基础设施研发及产业化项目408,000.00万元；超聚变智慧制造园区及研发中心项目203,000.00万元（项目投资额220,316.36万元）；面向智能算力、AI以及供电架构的关键技术研发项目89,000.00万元；补充流动资金100,000.00万元；合计募集资金投资额800,000.00万元【招股书 p.37】。
  • 公司说法：定位于"全球领先的水平全栈解决方案提供者"，聚焦AI、算力、数据、能源四大领域【招股书 p.37】。
  • 本次拟发行不低于9,781.3450万股且不高于22,008.0262万股，占发行后总股本不低于10%且不高于20%【招股书 p.7】。

四、行业什么样

行业增速快，但公司引用的口径要看清。

  • 根据IDC数据，2025年全球服务器市场出货量1,678万台，市场规模约4,441亿美元，增速80.4%；中国服务器市场出货量464万台，市场规模约768亿美元，增速46.0%【招股书 p.33】。
  • 根据IDC数据，2024年中国液冷服务器市场规模23.7亿美元、同比增长67.0%【招股书 p.33】。
  • 根据赛迪顾问数据，2025年中国国产化服务器销售额1,452.9亿元，同比增长68.4%【招股书 p.33】。

公司自己的市场地位表述（原文照录）：

  • "根据IDC数据，2025年公司服务器出货量市场占有率位居中国市场第二"【招股书 p.5】。
  • "2022年至2025年，公司服务器在中国市场的市场占有率从11.7%提升到14.2%，出货量排名跃升至第二位"——IDC统计数据【招股书 p.25】。
  • "公司国产化服务器销售额位居中国市场第一"【招股书 p.25】。
  • "2022年至2025年，公司标准液冷服务器市场份额均稳居中国市场第一"【招股书 p.25】。
  • "中国标准液冷服务器市场占有率连续四年稳居第一"——根据国际数据公司（IDC）报告【招股书 p.103】。
  • "公司是国产算力昇腾生态最高等级伙伴，出货金额与出货量在昇腾算力合作厂商中排名第一"【招股书 p.103】。
  • "公司2025年度在中国服务器市场占有率位居第二"——根据国际数据公司（IDC）报告【招股书 p.103】。
注：上述"第一/第二"均带IDC或赛迪顾问口径，原文未给出具体百分比的地方本稿不补。

五、生意里的数字反差

1. 收入越涨，经营现金流越负。

  • 营业收入2023年2,509,191.59万元 → 2025年5,824,616.34万元【招股书 p.35】。
  • 经营活动产生的现金流量净额：2023年-656,799.39万元 → 2024年-252,628.81万元 → 2025年-46,187.72万元 → 2026年1-6月-1,568,498.07万元【招股书 p.36】。
  • 公司解释：备货占用流动资金，上游付款账期短、下游回款周期长【招股书 p.43】。

2. 毛利率三年往下，半年往上。

  • 2023年14.27% → 2024年10.04% → 2025年8.58% → 2026年1-6月15.49%【招股书 p.18】。
  • 公司说2026年上半年提升与原材料涨价背景下供应链管控有关【招股书 p.18】。

3. 存货一路走高，跌价准备也在走。

  • 存货账面余额：2023年末976,747.26万元 → 2024年末1,818,811.10万元 → 2025年末2,120,564.08万元 → 2026年6月末3,566,241.42万元【招股书 p.19】。
  • 存货跌价准备余额：63,070.90万元 → 56,608.09万元 → 58,062.74万元 → 82,787.55万元【招股书 p.19】。

4. 应收账款半年翻倍多。

  • 应收账款余额：2023年末672,976.28万元 → 2024年末714,807.14万元 → 2025年末557,053.43万元 → 2026年6月末1,530,250.87万元【招股书 p.40】。
  • 占当期营业收入比例：26.82% → 16.15% → 9.56% → 41.04%【招股书 p.40】。

5. 客户集中度上升。

  • 前五大客户合计销售收入占比：2023年42.44% → 2024年54.99% → 2025年54.81% → 2026年1-6月50.81%【招股书 p.42】。

6. 供应商集中度也高。

  • 前五名生产物料供应商采购金额占比：2023年71.98% → 2024年74.49% → 2025年72.40% → 2026年1-6月64.92%【招股书 p.42】。
  • 第一大供应商占采购金额比例：34.50% → 52.06% → 38.01% → 31.32%【招股书 p.42】。
  • 2021年收购对价参考评估结果确定为570亿元【招股书 p.48】。
  • 2025年调整为330.1917亿元【招股书 p.51】。
  • 2025年12月增资按投前估值430亿元、折合53.75元/股【招股书 p.81】。
  • 员工持股按330.1917亿元评估值确定【招股书 p.81】。

8. 研发投入金额不低，但占收入比例往下走。

  • 研发投入：2023年122,871.84万元 → 2024年109,817.46万元 → 2025年117,825.18万元 → 2026年1-6月125,572.19万元【招股书 p.29】。
  • 占营业收入比例：4.90% → 2.48% → 2.02% → 3.37%【招股书 p.36】。

9. 新兴业务体量很小。

  • 2026年1-6月新兴业务合计13,883.01万元，占0.37%【招股书 p.119】。
  • 河南秦尉（智企生态业务主体）2026年1-6月营业收入17,323.92万元，净利润-14,514.15万元；2025年度净利润-8,590.32万元【招股书 p.71】。

六、值得关注的点 + 待核清单

值得关注的点（只列数字反差，不做判断）：

1. 经营现金流连续为负：四个报告期分别为-656,799.39万元、-252,628.81万元、-46,187.72万元、-1,568,498.07万元【招股书 p.36】。2026年上半年负数明显放大。

2. 存货与应收同时冲高：2026年6月末存货3,566,241.42万元【招股书 p.19】，应收账款1,530,250.87万元【招股书 p.40】，两者合计占2026年1-6月营业收入3,728,589.72万元【招股书 p.35】的比例可自行比对。

3. 毛利率与原材料价格的联动：2025年四季度以来内存、存储价格上行【招股书 p.18】，2026年上半年毛利率反而升至15.49%【招股书 p.18】。公司归因于供应链管控与议价能力。

4. 估值三次变化：570亿→330.1917亿→430亿（增资投前）【招股书 p.48】【招股书 p.51】【招股书 p.81】。

5. 客户与供应商双集中：前五大客户占比50.81%【招股书 p.42】，前五大供应商占比64.92%【招股书 p.42】，第一大供应商占31.32%【招股书 p.42】。

6. 新兴业务亏损：河南秦尉2026年1-6月净利润-14,514.15万元【招股书 p.71】。

7. 研发人员占比与研发投入占比的走向：研发人员1,449人占33.81%【招股书 p.100】，研发投入占收入比例从4.90%降到2.02%再回到3.37%【招股书 p.36】。

8. 募投项目含10亿补流：补充流动资金100,000.00万元，占募集资金投资额800,000.00万元的12.5%【招股书 p.37】。

待核清单：

  • [缺出处·待核] 2026年1-6月主营业务毛利率15.49%与2025年8.58%之间的具体产品结构变化拆分，文本只给了归因表述，未给分产品毛利率。
  • [缺出处·待核] 前五大客户具体名称，文本只写"互联网、运营商、国资算力企业等龙头企业"【招股书 p.42】，未列名。
  • [缺出处·待核] 第一大供应商具体名称，文本未披露【招股书 p.42】。
  • [缺出处·待核] "中国服务器市场占有率14.2%"的统计口径（销售额/出货量/出货金额）在p.25只写"市场占有率"，p.5写"出货量市场占有率位居第二"，两处口径表述不完全一致，需核对IDC原报告。
  • [缺出处·待核] "国产化服务器销售额位居中国市场第一"【招股书 p.25】未注明委托研究机构名与具体年份口径，需核对。
  • [缺出处·待核] "昇腾算力合作厂商中排名第一"【招股书 p.103】未注明数据来源机构与统计期间。
  • [缺出处·待核] 2026年1-6月经营活动现金流净额-1,568,498.07万元的具体构成（备货/应收/应付各自影响金额），文本未给明细。
  • [缺出处·待核] 境外收入中ECH关联交易占比，文本未在已给页码中披露。
  • [缺出处·待核] 员工持股计划授予价格与330.1917亿元估值的对应关系，p.81只写"根据超聚变330.1917亿元的评估值确定"，未给每股价格。
  • [缺出处·待核] 2025年12月增资53.75元/股与员工持股价格、2021年570亿估值对应每股价格的换算关系，文本未直接给出。
