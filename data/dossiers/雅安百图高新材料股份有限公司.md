# 【拆解档案】雅安百图高新材料股份有限公司

## 一、这是个什么生意

**一句话：把氧化铝等粉体"烧成小球"，卖给做导热材料的下游厂商。**

公司主业是"先进无机非金属功能性粉体材料的研发、生产和销售"【招股书 p.12】。主要产品三类：球形氧化铝、氮化物（球形氮化铝、球形氮化硼）、亚微米氧化铝【招股书 p.12】。

**产品卖到哪去：** 下游是导热材料厂商，最终用在新能源汽车、网络通信、消费电子等领域【招股书 p.12-13】。产品在产业链里的位置是"导热材料产业链的上游"【招股书 p.86】。

**收入靠什么：** 2025年主营业务收入 43,251.76 万元，其中球形氧化铝 32,739.96 万元，占 75.70%；氮化物 6,659.15 万元，占 15.40%；亚微米氧化铝 3,378.18 万元，占 7.81%；其他 474.47 万元，占 1.10%【招股书 p.87】。也就是说，四分之三的收入来自球形氧化铝这一个品类。

**客户是谁：** 招股书披露供应莱尔德、LG化学、瓦克化学、汉高等【招股书 p.13】。2025年前五大客户合计占营业收入 44.97%，第一大客户"单位A"占 16.58%【招股书 p.109】。

**怎么生产：** 核心工序自己干，个别成熟工序外协。报告期各期外协加工占营业成本比例均小于1%【招股书 p.88】。核心设备球化炉是自主设计的【招股书 p.17】。

**公司身份标签：** 国家级专精特新"重点小巨人"企业、国家级专精特新"小巨人"企业【招股书 p.12】。截至2025年12月31日，公司及控股子公司合计授权专利69项，其中发明专利20项，实用新型专利49项【招股书 p.17】。研发人员38名，占全部员工人数10.95%【招股书 p.17】。


## 二、赚不赚钱

**收入：** 2023年 28,574.58 万元 → 2024年 35,408.04 万元 → 2025年 43,639.17 万元【招股书 p.13】。三年连续增长。


**毛利率：** 2023年 45.69% → 2024年 45.03% → 2025年 41.52%【招股书 p.13】。三年往下走，2025年比2023年低4.17个百分点。

**扣非净利润：** 2023年 4,873.39 万元 → 2024年 5,126.79 万元 → 2025年 8,069.57 万元【招股书 p.13】。

**加权平均净资产收益率：** 2023年 7.08% → 2024年 6.22% → 2025年 10.24%【招股书 p.13】。扣非后分别为 6.23%、6.14%、9.83%【招股书 p.13】。

**经营活动现金流净额：** 2023年 9,135.13 万元 → 2024年 11,242.78 万元 → 2025年 13,181.38 万元【招股书 p.13】。三年都比当年净利润高。

**研发投入占营收比：** 2023年 6.92% → 2024年 5.30% → 2025年 4.55%【招股书 p.13】。逐年下降。

**资产负债率（母公司）：** 2023年 20.73% → 2024年 23.32% → 2025年 18.75%【招股书 p.13】。

**2026年一季度（未经审计或审阅）：** 营业收入 12,997.09 万元，同比增长16.96%；扣非净利润 2,702.48 万元，同比增长13.31%【招股书 p.6】。

**分红：** 报告期内两次分红，2024年7月派1,500.00万元（所属2023年度），2025年6月派2,500.00万元（所属2024年度）【招股书 p.28】。报告期后一次分红2,300.95万元（2025年度，每10股派6.75元含税）【招股书 p.5】【招股书 p.28】。


## 三、过去怎么走的，未来怎么说的

**过去三年（2023-2025）：**

- 球形氧化铝收入从 24,535.20 万元走到 32,739.96 万元，但占比从 86.46% 降到 75.70%【招股书 p.87】。
- 氮化物收入从 1,808.26 万元走到 6,659.15 万元，占比从 6.37% 升到 15.40%【招股书 p.87】。这是三年里结构变化最大的一块。
- 毛利率从 45.69% 降到 41.52%【招股书 p.13】。
- 境外销售收入占主营业务收入比例：21.91% → 26.12% → 26.79%【招股书 p.6】【招股书 p.20】。

**产能与产量（球形氧化铝）：** 产能从 11,328.00 吨增到 15,600.00 吨；产量从 7,927.37 吨增到 9,827.99 吨；产能利用率 69.98% → 59.59% → 63.00%【招股书 p.108】。产能扩了，利用率没同步跟上。

**亚微米氧化铝产能利用率：** 39.23% → 52.50% → 50.33%【招股书 p.109】。

**未来怎么说的（募投项目）：** 拟募资15,000.00万元投三个项目——电子导热新材料生产基地建设项目（拟投6,500.00万元，占43.33%）、高导热超细粉体产业化项目（拟投2,500.00万元，占16.67%）、雅安百图研发中心建设项目（拟投6,000.00万元，占40.00%）【招股书 p.18】。

**行业未来的说法（引用第三方数据）：** 根据赛迪网数据，全球中高导热粉体市场规模2023年为51.38亿元，预计2030年增长至132.30亿元；其中球形氧化铝市场规模预计由2023年的32.99亿元增长至2030年的76.22亿元【招股书 p.97】。


## 四、行业什么样

**行业归属：** 国民经济行业分类为"C3099其他非金属矿物制品制造"；战略性新兴产业分类为"3.4.5.4功能性填料制造"【招股书 p.93】。

**竞争格局（原文照录）：**

- "根据高工产业研究院数据，日本主要球形氧化铝企业包括日本电气化学、昭和电工、日本雅都玛以及新日铁等。国内主要球形氧化铝企业包括百图股份、联瑞新材、泽希新材等。"【招股书 p.104】
- "根据高工产业研究院数据，全球氮化铝导热粉体市场中日本德山和日本丸和市场份额较高。"【招股书 p.104】
- "全球氮化硼导热粉体市场中法国圣戈班市场份额较高"【招股书 p.105】

**公司市场地位（原文照录）：** "根据头豹研究院数据，公司处于中国导热粉体行业第一梯队。"【招股书 p.105】——注意：这里只给了"第一梯队"的定性表述，招股书文本中未见具体市占率百分比数字。

**行业门槛的说法：** 招股书列了技术壁垒、品牌壁垒、市场壁垒、资质壁垒四条【招股书 p.101-102】。其中提到"对于新晋企业，产能大规模释放最少需要1.5年时间"【招股书 p.102】。

**竞争加剧的表述（原文照录）：** "近几年粉体生产企业进行多元化发展，逐步新增或扩大球形氧化铝产能，包括联瑞新材、壹石通等企业产能新建项目较多，产能增长较快，使得产品供给增加，产品价格竞争加剧。"【招股书 p.103】

**同行业收入对比（招股书披露）：** 联瑞新材2025年营业收入111,550.35万元（2024年球形氧化铝产品收入13,763.25万元，2025年未拆分）；壹石通2025年无机功能粉体材料营业收入57,150.68万元；天马新材2025年营业收入27,365.97万元；金戈新材2025年导热粉体材料收入35,885.39万元；公司2025年主营业务收入43,251.76万元【招股书 p.107-108】。


## 五、生意里的数字反差


球形氧化铝产能从2023年11,328.00吨到2025年15,600.00吨【招股书 p.108】，增了约37.7%；产能利用率从69.98%到63.00%【招股书 p.108】。亚微米氧化铝产能从1,020.00吨到1,400.00吨【招股书 p.109】，产能利用率从39.23%到50.33%【招股书 p.109】。


研发投入占营业收入比例 6.92% → 5.30% → 4.55%【招股书 p.13】。

2025年经营现金流净额13,181.38万元 vs 净利润8,407.52万元；2024年11,242.78万元 vs 5,196.45万元；2023年9,135.13万元 vs 5,539.40万元【招股书 p.13】。

报告期各期末应收账款账面净额分别为10,837.46万元、9,710.93万元、10,854.89万元，占流动资产比例分别为30.35%、23.38%、21.37%【招股书 p.20】。

2025年前五大供应商合计占采购总额52.56%，第一大是天然气供应商（17.40%），第二大是电力供应商（13.48%）【招股书 p.112】。能源采购合计：天然气3,906.75万元、电2,612.73万元、氧气580.39万元，合计7,099.87万元【招股书 p.111】。

成都百图2025年净利润-545.98万元【招股书 p.55】；上海百图2025年净利润-465.91万元，净资产-399.16万元【招股书 p.56】；香港百图2025年净利润-6.37万元【招股书 p.56】；苏州梵丝2025年净利润-191.57万元【招股书 p.57】。参股公司立之亿2025年净利润-455.15万元，净资产-61.68万元【招股书 p.57】。

招股书原文："百图股份就上述三次减资事项进行了公告，但均未逐一通知各债权人，不符合《公司法》关于'公司应当自股东会作出减少注册资本决议之日起十日内通知债权人……'之规定，减资程序存在一定的瑕疵。"【招股书 p.27】

2025年度分红23,009,487.08元【招股书 p.5】，2025年净利润84,075,206.36元【招股书 p.13】。招股书称"不存在上市前突击大额或高比例现金分红"【招股书 p.5】。


## 六、值得关注的点 + 待核清单

**值得关注的点（只列客观事实，不做判断）：**

1. **产品结构集中度高。** 球形氧化铝一个品类占2025年主营收入75.70%【招股书 p.87】。氮化物占比从6.37%升到15.40%【招股书 p.87】，是第二大品类。

2. **毛利率三年连降。** 45.69% → 45.03% → 41.52%【招股书 p.13】。招股书在风险因素中写"产品价格和行业毛利率存在下滑风险"【招股书 p.20】。

3. **产能利用率不足七成。** 球形氧化铝2025年产能利用率63.00%【招股书 p.108】，同时募投项目还要扩产【招股书 p.18】。

4. **境外收入占比上升。** 21.91% → 26.12% → 26.79%【招股书 p.6】。招股书称氧化铝产品在美国"对等关税"豁免清单中【招股书 p.6】。

5. **前五大客户集中度约45%。** 2025年44.97%【招股书 p.109】，2024年47.38%【招股书 p.110】，2023年45.57%【招股书 p.110】。第一大客户"单位A"以代称披露，未具名【招股书 p.109】。


7. **三次减资程序瑕疵。** 招股书自述"未逐一通知各债权人，不符合《公司法》"【招股书 p.27】，实际控制人已出具补偿承诺【招股书 p.27】。

8. **子公司普遍亏损。** 成都百图、上海百图、香港百图、苏州梵丝2025年净利润均为负【招股书 p.55-57】。

9. **研发人员38名，硕士博士占比超50%** 【招股书 p.17】；研发投入占比逐年下降【招股书 p.13】。

10. **股权代持历史。** 招股书披露历史上存在多起股权代持，均已在报告期前解除【招股书 p.37-39】。
