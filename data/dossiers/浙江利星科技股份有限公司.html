一、这是个什么生意

利星科技做的是石化用催化剂和助剂。简单说，就是卖给PTA（精对苯二甲酸）、PET（聚酯）、TMA（偏苯三酸酐）工厂用的“反应加速剂”。公司自己的描述是：以助催化剂氢溴酸为根基，构建了以PTA、PET、TMA催化剂与助剂为核心、农药中间体原料为辅助的业务板块，形成溴系、钴锰系、锑钛系三大产品线【招股书 p.12】。

产品分三大类：

  • 溴系：氢溴酸、四溴乙烷、溴化氢乙酸溶液，主要作为PTA生产的助催化剂【招股书 p.72】
  • 钴锰系：醋酸钴、醋酸锰、醋酸钴锰、钴锰溴等，在PX制PTA的氧化反应中做催化剂【招股书 p.73】
  • 锑钛系：乙二醇锑、钛系催化剂，用于PET聚酯生产的缩聚反应【招股书 p.73-74】

公司有四大生产基地：浙江绍兴、山东潍坊、辽宁大连、海南儋州【招股书 p.21】。另有浙江金海湾和利星新材料作为购销平台，集中采购原材料和销售产品【招股书 p.78】。

客户是谁？前十大客户包括恒逸石化、荣盛石化、恒力石化、桐昆股份、东方盛虹、新凤鸣、中国石化等A股上市企业【招股书 p.21】。TMA客户有正丹股份、百川股份、泰达新材；农药客户有扬农化工、雅本化学【招股书 p.13】。

经营模式分三种：自产、复配、贸易。自产是买原料自己反应制造；复配是把原料按配方物理混合；贸易是买成品直接转卖【招股书 p.74-75】。

2025年主营业务收入中，自产占51.96%，复配占26.87%，贸易占21.16%【招股书 p.101】。

经营活动现金流净额：2023年22,195.32万元，2024年2,813.61万元，2025年-2,328.21万元【招股书 p.13】。

三、过去怎么走的，未来怎么说的

过去四个阶段（公司自己划分的）【招股书 p.76-77】：

1. 2002-2006年：技术积累，开发液体催化剂实现国产化

2. 2007-2011年：在山东潍坊建生产基地，靠近溴素来源

3. 2012-2017年：在PTA聚集地周边建生产基地，进入民营石化头部企业供应链

4. 2018年至今：切入聚酯催化剂领域，开发钛系催化剂

收入结构变化（主营业务收入占比）【招股书 p.74】：

钴锰系（液体）销量：2023年25,729.19吨 → 2024年25,357.78吨 → 2025年22,091.89吨，逐年下降【招股书 p.26】。公司解释是下游客户对钴锰废料回收再利用比例提升，对外采购需求降低【招股书 p.26】。

未来要做什么：

  • 募投项目：聚酯催化剂生产基地建设项目（拟投42,843.39万元）、研发中心建设项目（拟投11,662.82万元）、补充流动资金（6,000万元），合计60,506.21万元【招股书 p.22】
  • 募投项目建成后预计新增年产6,000吨乙二醇锑、3,000吨钛系新型聚酯催化剂、10,000吨氧化锑产能【招股书 p.27】
  • 正在推广钛系催化剂，布局多相催化剂（PTA加氢还原用钯炭催化剂的替代）和3D打印催化剂载体【招股书 p.17-18】

氢溴酸压降承诺：公司在新三板挂牌时承诺，2025年氢溴酸复配和自制产量不超过39,500吨，2026-2029年每年压降500吨，至2029年压降至37,500吨；至2029年度，复配和自制氢溴酸对外销售收入占主营业务收入比例从2024年1-7月的39.65%下降至30%以内【招股书 p.70】。

四、行业什么样

行业归属：C26化学原料和化学制品制造业 → C2661化学试剂和助剂制造【招股书 p.12】。

全球催化剂市场：根据QY Research统计及预测，2025年全球催化剂市场销售额293.61亿美元，预计2032年达389.75亿美元【招股书 p.85】。全球前五大厂商（BASF、Johnson Matthey、Umicore、Grace、Cataler）占有约60%份额【招股书 p.85】。

中国催化剂市场：2019-2024年从843.9亿元增长至1,192.3亿元，复合增长率7.16%【招股书 p.86】。数据来源为观知海内信咨询、华经产业研究院【招股书 p.87】。

PTA催化剂市场：根据QY Research统计及预测，2025年全球PTA催化剂市场规模约6.54亿美元，预计2032年达8.3亿美元【招股书 p.87】。

PET催化剂市场：根据QY Research统计及预测，2025年全球聚酯催化剂市场规模8.57亿美元，预计2032年达9.76亿美元【招股书 p.88】。

PTA行业格局：2025年全国PTA总产能9,209.00万吨，实际产量7,376.00万吨，消费量7,007.00万吨【招股书 p.89】。恒逸石化、荣盛石化、恒力石化、桐昆股份四大民营石化企业及其子公司产能合计占比约50%【招股书 p.89】。

PET行业格局：2025年全国PET总产能8,972.00万吨，实际产量7,984.00万吨，消费量6,581.00万吨【招股书 p.90】。预计2026年底产能达9,394.00万吨左右【招股书 p.90】。

TMA行业格局：国内基本形成正丹股份、百川股份、泰达新材三大企业占据主要产能的格局【招股书 p.91】。

公司市场地位（原文照录）：根据中国化学纤维工业协会2025年1月出具的证明，公司钴锰系产品、溴系核心产品氢溴酸在国内PTA市场占有率排名第一，锑钛系核心产品乙二醇锑在国内PET市场占有率排名第三【招股书 p.13】。另处披露：公司钴锰系催化剂和氢溴酸产品在国内PTA市场占有率均超过60%，排名行业第一；乙二醇锑产品在国内PET市场占有率超过10%【招股书 p.95】。

可比公司：PTA氧化催化剂与助剂板块选南京试剂（833179.NQ）、苏利股份（603585.SH）；聚酯催化剂板块选湖南黄金（002155.SZ）【招股书 p.98】。

五、生意里的数字反差

1. 收入涨了，经营现金流反而转负

2025年营业收入138,136.74万元，比2024年103,906.24万元增长约33%【招股书 p.13】。但2025年经营活动现金流净额为-2,328.21万元，2024年为2,813.61万元，2023年为22,195.32万元【招股书 p.13】。收入创新高，经营现金流为三年最低。

2. 应收账款增速快于收入增速

应收账款账面价值：2023年末18,036.59万元 → 2024年末20,632.66万元 → 2025年末33,953.06万元【招股书 p.25】。2025年比2024年增加约64.6%。同期营业收入增长约33%。应收账款占资产总额比例从17.63%升至22.25%【招股书 p.25】。

3. 存货持续增加

存货账面价值：2023年末16,013.44万元 → 2024年末23,774.20万元 → 2025年末30,989.37万元【招股书 p.25】。占流动资产比例从20.83%升至27.83%【招股书 p.25】。

4. 钴锰系销量逐年下降，但锑钛系销量快速增长

钴锰系（液体）销量：25,729.19吨 → 25,357.78吨 → 22,091.89吨【招股书 p.26】。乙二醇锑销量：2,248.38吨 → 3,238.10吨 → 3,770.82吨【招股书 p.103】。

5. 氢溴酸（自制）产能利用率偏低

2023年37.44%，2024年37.84%，2025年51.62%【招股书 p.102】。公司解释是潍坊生产基地新装置2023年9月逐步投产，处于调试爬坡期【招股书 p.103】。

绍兴生产基地2025年氢溴酸（复配）产量23,878.18吨，批复产能20,000吨【招股书 p.103】。公司披露超产比例未超过30%【招股书 p.103】。

2024年产能1,500吨，产量1,920.18吨【招股书 p.102】。公司已建设技改项目新增2,500吨/年产能，总产能提高至4,000吨/年【招股书 p.103】。

利星科技2023-2025年研发投入占营业收入比例分别为0.89%、1.03%、0.97%【招股书 p.100】。南京试剂同期为4.19%、4.54%、3.85%；苏利股份为5.36%、4.88%、4.05%；湖南黄金为1.48%、1.16%、0.69%【招股书 p.99-100】。公司研发人员15人，占比8.15%【招股书 p.100】。

9. 前五大客户占比在下降，但绝对金额在上升

前五大客户销售金额：63,772.83万元 → 56,663.97万元 → 64,403.13万元；占营业收入比例：62.73% → 54.53% → 46.62%【招股书 p.6】。占比下降，但2025年绝对金额超过2023年。

三氧化二锑平均采购价格：2023年6.27万元/吨 → 2024年9.56万元/吨 → 2025年13.17万元/吨【招股书 p.104】。金属钴平均采购价格：21.94 → 13.91 → 21.34万元/吨【招股书 p.105】。溴素：2.16 → 1.73 → 2.36万元/吨【招股书 p.105】。

12. 汇兑损益波动

2023年汇兑损失30.90万元，2024年354.66万元，2025年-29.45万元（即收益）【招股书 p.25】。

13. 分红情况

包苏春和包玉莲系姐弟关系，分别直接持股19.40%和19.12%，通过金海湾控股控制55.48%，通过利城企管和利海企管控制3.22%，合计控制97.23%表决权【招股书 p.6】。

六、值得关注的点 + 待核清单

值得关注的点：

1. 经营现金流与净利润的背离：2025年净利润14,569.82万元，经营现金流净额-2,328.21万元【招股书 p.13】。应收账款和存货都在快速增加。

2. 产品结构在切换：钴锰系收入占比从29.39%降到18.39%，锑钛系从10.79%升到27.03%【招股书 p.74】。钴锰系销量逐年下降【招股书 p.26】。

3. 超产能生产：氢溴酸（复配）2025年产能利用率119.39%【招股书 p.103】，乙二醇锑2024年产能利用率128.01%【招股书 p.102】。公司已通过技改项目解决乙二醇锑超产问题。

4. 氢溴酸压降承诺：公司承诺2025-2029年逐年压降氢溴酸复配和自制产量【招股书 p.70】。氢溴酸属于“高污染、高环境风险”产品【招股书 p.70】。

5. 研发投入占比低：不到1%，在可比公司中处于较低水平【招股书 p.100】。

6. 原材料进口依赖：工业级氢溴酸、溴素进口依存度较高，全球产能集中于以色列、约旦等中东地区【招股书 p.5】。主要供应商ICL集团、ALB集团【招股书 p.5】。

7. 募投项目新增产能较大：预计新增6,000吨乙二醇锑、3,000吨钛系新型聚酯催化剂、10,000吨氧化锑产能【招股书 p.27】。公司也提示了产能消化风险。

8. 钛系催化剂推广不确定性：公司正在向下游客户推广钛系催化剂，若推广不顺可能影响募投项目实施效果【招股书 p.27】。

待核清单：

  • [缺出处·待核] 公司各产品在PTA/PET市场占有率的第三方证明原文，招股书仅引述中国化学纤维工业协会2025年1月出具的证明结论【招股书 p.13】，未附证明全文。
  • [缺出处·待核] 公司2026年1-6月业绩预计的具体假设条件和测算过程，招股书仅给出预计区间和简要原因【招股书 p.7】。
  • [缺出处·待核] 公司历史沿革中2022年股权激励公允价值23.08元/股的评估报告详细内容【招股书 p.37】。
