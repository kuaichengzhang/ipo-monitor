# 【拆解档案】深圳市沃客非凡科技股份有限公司

### 一、这是个什么生意

这家公司叫沃客非凡，简单说，就是**把中国生产的手机配件、小家电、家装建材，卖到印尼等东南亚国家去**。

- 它自己搞了好几个牌子，比如VIVAN、ROBOT（卖充电宝、充电线）、SAMONO（卖绞肉机、烤箱）【招股书 p.10】。
- 2025年，它收入的93.4%来自自有品牌【招股书 p.10】。
- 它不自己开工厂，主要从中国的OEM/ODM供应商那里进货【招股书 p.14】。
- 卖货主要靠两条腿：线下卖给中小零售商（SMR），线上在Shopee、Tokopedia开网店【招股书 p.11】。
- 截至2026年6月30日，跟它有过交易的中小零售商有36,318家【招股书 p.11】。
- 它在印尼、越南、泰国、菲律宾四个国家做生意，但绝大部分收入来自印尼【招股书 p.11】。

### 二、赚不赚钱

**赚是赚，但赚得挺辛苦，利润率不算高。**

**收入盘子（单位：人民币）**

**利润情况（单位：人民币）**
- 2023年净利润1831.9万元【招股书 p.16】
- 2024年净利润2035.3万元【招股书 p.16】
- 2025年净利润4795.2万元【招股书 p.16】
- 2026年上半年净利润2479.6万元【招股书 p.16】

**赚钱效率**
- 毛利率在涨：从2023年的33.6%涨到2025年的37.1%，2026年上半年是38.7%【招股书 p.12】。
- 但净利率很低：2023年只有2.0%，2024年1.9%，2025年3.9%，2026年上半年3.5%【招股书 p.24】。
- 钱主要花在哪了？销售及分销开支占了大头，2025年花了2.7亿元，占收入的22.2%【招股书 p.16】。

**一个关键点：账面利润和实际到手钱不一样**
- 公司算了一个“经调整净利润”，把一些非现金或一次性项目加回去了。
- 2025年报表净利润是4795.2万元，但经调整净利润是8080.6万元【招股书 p.17】。
- 差在哪？主要是“赎回负债账面值变动”这一项，2025年加了2524.6万元【招股书 p.17】。这个负债跟股东的特殊权利有关，上市后会转成权益【招股书 p.17】。

### 三、过去怎么走的，未来怎么说的

**过去三年，公司干了几件事：**

1. **产品结构变了**：3C配件占比从2023年的76.2%降到2026年上半年的58.0%【招股书 p.18】。小家电涨得猛，从4.4%涨到20.9%【招股书 p.18】。
2. **渠道变了**：以前主要靠线下分销商，现在线上直营越做越大。分销商收入占比从2023年的82.8%降到2026年上半年的64.4%【招股书 p.19】。直接客户（包括线上消费者）占比从17.2%涨到34.5%【招股书 p.19】。
3. **地域上还是靠印尼**：印尼收入占比一直很高，2023年是95.9%，2026年上半年是93.0%【招股书 p.20】。越南、泰国、菲律宾加起来还不到7%【招股书 p.20】。

**未来公司打算这么干：**
- 继续做品牌，扩大产品种类【招股书 p.12】。
- 扩大客户群，加强获客【招股书 p.12】。
- 搞数字化升级【招股书 p.12】。
- 上市募的钱，计划主要花在供应链仓储、营销渠道、品牌影响力、数字化升级这些地方【招股书 p.26】。

### 四、行业什么样

**公司主要看印尼市场，行业数据也主要来自印尼。**

- **整体零售市场**：印尼零售市场2025年规模约3,330亿美元，预计2030年增长到4,457亿美元【招股书 p.10】。
- **线下为主**：2025年，印尼线下零售还占整个市场的79.1%【招股书 p.10】。线下渠道里，那种小卖部、家庭式商店（一般贸易）又占了线下的大头，2025年约占71.7%【招股书 p.83】。
- **3C配件市场**：印尼3C配件市场2025年约73亿美元，预计2030年达到108亿美元，复合年增长率8.1%【招股书 p.85】。
- **小家电市场**：印尼小家电市场2025年约19亿美元，预计2030年达到25亿美元，复合年增长率5.4%【招股书 p.88】。
- **家装建材市场**：印尼家装建材市场2025年约125亿美元，预计2030年达到171亿美元，复合年增长率6.5%【招股书 p.90】。

**公司在行业里的位置（注意口径）：**
- 根据弗若斯特沙利文的资料，以2025年零售价值计算，公司于印度尼西亚的3C配件领域位居第一，市场占有率约为2.2%【招股书 p.10】。
- 根据弗若斯特沙利文的资料，在小家电领域方面，公司在中国跨境企业中排名第六，占中国对印度尼西亚小家电出口市场的市场占有率约3.7%【招股书 p.10】。
- 2025年，印尼前五大3C配件公司加起来才占市场总额约5.5%【招股书 p.94】。说明这个市场非常分散，第一名也只有2.2%【招股书 p.94】。

### 五、生意里的数字反差

1. **“第一”和“份额”的反差**：公司是印尼3C配件领域排名第一的公司【招股书 p.10】，但市场占有率只有约2.2%【招股书 p.10】。前五名加起来也就5.5%【招股书 p.94】。这个“第一”的含金量，得看你怎么理解。

2. **毛利率和净利率的反差**：毛利率从33.6%涨到38.7%【招股书 p.12】，看着不错。但净利率一直在2%-4%之间徘徊【招股书 p.24】。钱被销售费用吃掉了，2025年销售及分销开支占收入的22.2%【招股书 p.16】。


4. **线上渠道的“增收不增利”**：线上直营收入占比从2023年的17.2%涨到2026年上半年的34.5%【招股书 p.19】，但给电商平台的佣金费率也在猛涨，从2023年的8.7%涨到2026年上半年的16.8%【招股书 p.46】。线上卖得越多，平台抽成越狠。



### 六、值得关注的点 + 待核清单

**值得关注的点：**


2. **线上渠道的成本**：电商平台佣金费率从8.7%涨到16.8%【招股书 p.46】，这个趋势如果继续，线上卖得越多，利润可能越薄。

3. **存货压力**：存货周转天数从55天涨到82天【招股书 p.44】，如果产品卖不动，可能会有跌价风险。

4. **“第一”的成色**：虽然说是印尼3C配件第一【招股书 p.10】，但市场份额只有2.2%【招股书 p.10】，而且前五名加起来才5.5%【招股书 p.94】。这个市场极度分散，护城河到底有多深，需要打个问号。

5. **上市前的“特殊安排”**：公司账上有一笔“赎回负债”，2025年变动了2524.6万元【招股书 p.17】。公司说上市后会转成权益【招股书 p.17】。这笔钱的性质和影响，值得搞清楚。

**待核清单：**

1. [缺出处·待核] 公司提到“根据弗若斯特沙利文的资料，以2025年零售价值计算，我们于印度尼西亚的3C配件领域位居第一，市场占有率约为2.2%”【招股书 p.10】。这个“零售价值”具体是怎么算的？是终端零售价还是出厂价？需要看弗若斯特沙利文报告的详细口径。

2. [缺出处·待核] 公司提到“于往绩记录期间，我们与东南亚合共超过60,000家SMR建立合作关系”【招股书 p.11】，但后面又说“当中包括36,318家SMR与我们在截至2026年6月30日已录得交易”【招股书 p.11】。这6万多家是累计数，3.6万多家是当期活跃数，这个口径差异需要确认。

3. [缺出处·待核] 公司提到“截至2026年6月30日，我们已与SMR客户建立广泛的联系，使我们在印度尼西亚确立3C配件及小家电领域跨境品牌企业的地位”【招股书 p.10】。这个“地位”是公司自己说的，还是第三方机构认证的？需要看有没有具体排名依据。

4. [缺出处·待核] 公司提到“于2025年，93.4%的收入来自自有品牌”【招股书 p.10】。但按品牌划分的收入明细表里，ROBOT、VIVAN、SAMONO、RONA加起来是84.5%【招股书 p.14】，剩下的“其他自有品牌”占15.6%【招股书 p.14】。这些“其他自有品牌”具体是哪些牌子，占收入的比重不小，需要列清楚。

5. [缺出处·待核] 公司提到“截至2026年6月30日，我们在多个电商平台上管理71家官方旗舰店”【招股书 p.11】，但后面又说“线上商店由2023年的约90间增至截至2026年6月30日的超过150间”【招股书 p.19】。71家和150间口径不一样，需要确认哪个是旗舰店，哪个是所有店铺。
