一、这是个什么生意

一句话：卖金属加工用的激光设备，主要卖给外国人。

公司主业是激光加工设备及智能制造生产线的研发、生产、销售及服务【招股书 p.16】。主要产品分三块：

1. 激光加工设备——核心是光纤激光切割设备，另有激光焊接设备、激光熔覆设备等【招股书 p.16】。

2. 智能制造生产线——激光柔性加工生产线、智能钣金折弯中心、钣金成形柔性生产线等【招股书 p.16】。

3. 激光熔覆服务——给煤炭、石化等行业的轴类零件做表面修复【招股书 p.116-p.117】。

收入结构（主营业务收入，单位：万元）【招股书 p.118】：

|---|---|---|---|---|

激光加工设备里，光纤激光切割设备又占八成以上：2026年1-6月占激光加工设备收入的83.41%【招股书 p.118】。

卖给谁： 客户覆盖一百余个国家及地区【招股书 p.16】。下游行业包括工程机械、汽车零部件、桥梁建筑模板、装配式建筑、特变电输送铁塔、煤炭开采及石油化工设备等【招股书 p.16】。

怎么卖： 国内以直销为主，国际直销、经销并存【招股书 p.120】。截至2026年6月末，仅在埃及、捷克、波兰、法国、罗马尼亚等国有15家独家代理经销商【招股书 p.121】。

谁说了算： 控股股东、实际控制人是李峰西、李雷夫妇，两人合计直接持有公司61.70%的股份【招股书 p.15】。李峰西任董事长、总经理、法定代表人【招股书 p.37】。

上市地： 北京证券交易所【招股书 p.1】。本次拟发行不超过1,900万股【招股书 p.4】。

二、赚不赚钱

核心财务数据（单位：元）【招股书 p.17】

|---|---|---|---|---|

几个关键观察

1. 收入在原地打转，2025年才回到2023年水平之上。

营业收入2023年13.30亿元，2024年12.96亿元，2025年14.67亿元【招股书 p.17】。2024年比2023年少了约3,300万元，2025年比2024年多了约1.7亿元。

2. 净利润连续三年下滑，但扣非净利润2025年反弹。

归母净利润：2023年10,793.45万元 → 2024年10,099.77万元 → 2025年9,793.59万元【招股书 p.5】。但扣非归母净利润2024年7,626.85万元 → 2025年9,020.66万元【招股书 p.25】。招股书解释：2025年"受政府补助减少的影响，虽当期扣非净利润同比大幅增长但当期净利润略有下降"【招股书 p.6】。

3. 毛利率稳，主营业务毛利率还略升。

主营业务毛利率分别为30.09%、31.66%、31.81%和32.83%【招股书 p.29】。招股书说"受上游零部件价格下降的影响，公司产品销售价格呈下降趋势，但主营业务毛利率保持稳定"【招股书 p.29】。

4. 外销占比越来越高。

外销主营业务收入占主营业务收入比例：2023年66.00%、2024年68.46%、2025年74.88%、2026年1-6月72.42%【招股书 p.33】。外销金额分别为84,929.94万元、83,265.04万元、98,599.71万元和50,269.03万元【招股书 p.6】。

5. 内销在缩。

内销主营业务收入：2023年43,752.62万元 → 2024年38,363.74万元 → 2025年33,077.95万元 → 2026年1-6月19,139.65万元【招股书 p.28】。招股书说2024、2025年下降原因包括"公司境内营销投入相对不足"【招股书 p.28】。

6. 研发投入占比在降。

研发投入占营业收入比例：2023年5.65%、2024年4.98%、2025年4.69%、2026年1-6月3.94%【招股书 p.17】。最近三年研发投入分别为7,509.34万元、6,455.22万元和6,885.95万元，平均6,950.17万元，最近三年研发投入占营业收入比例5.09%【招股书 p.21】。

7. 经营现金流为正，但2023年明显高于后几年。

经营活动产生的现金流量净额：2023年157,234,297.45元、2024年67,778,956.38元、2025年80,049,517.01元、2026年1-6月79,270,885.38元【招股书 p.17】。

8. 资产负债率（母公司）在降。

2023年65.22% → 2024年61.93% → 2025年56.61% → 2026年6月末54.40%【招股书 p.17】。

三、过去怎么走的，未来怎么说的

过去怎么走的

三个阶段【招股书 p.122-p.123】：

  • 2007-2014年：起步。 成立之初做激光印章雕刻设备，后来做CO₂激光雕刻设备、激光打标机。2014年启动光纤激光切割设备研发。
  • 2020年至今：快速发展。 进入激光熔覆领域，开发超高速激光熔覆机床、机器人熔覆工作站等；产品矩阵扩展到智能制造生产线。

收入轨迹（主营业务收入，万元）【招股书 p.5】：

  • 2024年：121,628.78（下降，招股书说受国际贸易政策波动影响，境外市场业务受到一定影响【招股书 p.5】）

产品结构变化：智能制造生产线收入从2023年7,986.80万元涨到2025年20,920.52万元，占比从6.21%升到15.89%【招股书 p.118】。激光加工设备占比从91.23%降到81.23%【招股书 p.118】。

四、行业什么样

行业定位

按《国民经济行业分类》（GB/T4754-2017），公司属于"制造业（C）"之"通用设备制造业（C34）"；按《挂牌公司管理型行业分类指引（2023年修订）》，属于"金属切割及焊接设备制造（CG3424）"【招股书 p.128】。

行业规模（数据来源均为《2026中国激光产业发展报告》，原文照录）

  • 2025年我国激光加工设备行业市场规模达到958亿元，预计2026年达到1,080亿元【招股书 p.137】。
  • 2025年激光切割设备市场规模315.2亿元，占激光加工设备行业32.90%；预计2026年激光切割设备行业市场规模324.1亿元【招股书 p.139】。
  • 2023年中国激光焊接成套设备市场销售收入115.2亿元，同比增长38.63%，预计2026年达到240.1亿元【招股书 p.141-p.142】。
  • 根据《2025中国激光产业发展报告》，2024年我国激光熔覆设备行业市场规模达77亿元，预计2025年达到88.7亿元【招股书 p.144】。

核心零部件国产化情况（《2026中国激光产业发展报告》）

  • 6-10KW功率段光纤激光器市场，2025年国内自产光纤激光器市场份额达到90.1%【招股书 p.136】。
  • 10KW以上功率段光纤激光器市场，2025年国内自产光纤激光器市场份额达到78.3%【招股书 p.136】。

公司自己的市占率表述（原文照录）

"根据《2026中国激光产业发展报告》统计数据，2025年公司在华市场（含出口）销售激光切割成套设备市场份额占比为4.6%，公司激光切割设备在华市场占据重要地位。"【招股书 p.24】

注意口径：这是"在华市场（含出口）"的"激光切割成套设备"市场份额，不是全球市场，也不是全部激光加工设备。

行业趋势（招股书归纳）

1. 核心零部件逐步实现国内自产【招股书 p.136】。

2. 下游应用领域广泛，持续向高功率、短波长、窄脉宽方向发展【招股书 p.136】。

3. 激光加工设备日趋数字化、智能化【招股书 p.137】。

4. 日趋集成化、柔性化【招股书 p.138】。

5. 应用领域不断拓展【招股书 p.138】。

竞争格局

招股书在释义里列了同行业公司：华工科技（000988.SZ）、大族激光（002008.SZ）、海目星（688559.SH）、联赢激光（688518.SH）【招股书 p.12】。但提供的文本中没有各家的具体市场份额数字 [缺出处·待核]。

2. 净利润三年连降，扣非净利润2025年却大增。

归母净利润2023年10,793.45万元 → 2024年10,099.77万元 → 2025年9,793.59万元【招股书 p.5】；扣非归母净利润2024年7,626.85万元 → 2025年9,020.66万元【招股书 p.25】。两者方向相反，差额来自政府补助等非经常性损益的变化。

存货账面价值：2023年末27,101.10万元 → 2024年末33,496.61万元 → 2025年末32,901.26万元 → 2026年6月末34,010.13万元【招股书 p.6-p.7】。占流动资产比例分别为29.77%、32.48%、31.57%、30.62%【招股书 p.7】。

6. 核心原材料靠外购，自产激光器"应用比例仍然较低"。

激光器、切割头等激光光学类原材料采购占总采购额比例：42.87%、35.83%、35.48%、37.61%【招股书 p.6】。招股书说公司已具备1-4KW系列单模块光纤激光器以及6-20KW系列多模块光纤激光器生产能力，但"公司当前激光器品牌竞争优势尚未凸显，自产激光器在产品中的应用比例仍然较低"【招股书 p.6】。

2025年9月10日股东会审议通过2025年半年度权益分派方案，每10股派8.77元（含税），共计派发现金红利4,998.90万元【招股书 p.37】。2025年归母净利润9,793.59万元【招股书 p.5】。

六、值得关注的点 + 待核清单

值得关注的点（只列客观数字反差，不做判断）

1. 外销占比与"分散"的对应关系。 2025年外销占主营收入74.88%【招股书 p.33】，主要销售市场为北美、欧洲、亚太等地区【招股书 p.6】。单个国家/地区收入占比数据在提供文本中未披露 [缺出处·待核]。

2. 内销连续两年下降后的恢复情况。 2026年1-6月内销19,139.65万元，招股书说"已实现明显增长"【招股书 p.28】，但提供文本中没有2025年1-6月内销可比数字 [缺出处·待核]。

4. 自产激光器的实际使用比例。 招股书说"自产激光器在产品中的应用比例仍然较低"【招股书 p.6】，但没有给出具体百分比 [缺出处·待核]。

5. 募投用地未落实。 截至招股书签署日尚未取得募投项目用地【招股书 p.8】。预留约305亩、二期约153亩【招股书 p.8】。

6. 募投新增折旧占2025年净利润22.17%。 完全投产后每年新增折旧摊销2,193.52万元【招股书 p.33】。

7. 对赌回购条款的触发条件。 涉及"公司自股票在全国股转系统挂牌之日起满18个月仍未向证券交易所提交上市申请材料"等条款【招股书 p.7】。公司挂牌日期为2025年7月21日【招股书 p.15】。

8. 实控人2,500万元或有债务的触发条件与北交所上市无关，但与沪深IPO有关【招股书 p.7】。

9. 2025年分红4,998.90万元 vs 2025年归母净利润9,793.59万元【招股书 p.37】【招股书 p.5】。

11. 研发费用率连续下降：5.65% → 4.98% → 4.69% → 3.94%【招股书 p.17】。

12. 2026年全年业绩预计为初步预计数据，未经会计师审计或审阅，不构成盈利预测或业绩承诺【招股书 p.9】。
