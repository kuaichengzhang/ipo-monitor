# 【医疗拆解档案】四川百利天恒藥業股份有限公司

> 港交所·主板 · 申报受理 · https://www1.hkexnews.hk/app/sehk/2026/108787/documents/sehk26080601693_c.pdf 
> 机器生成底稿 · 校验闸门:109 句通过,94 句拦截

## 一句话概览

这家公司做两件事：一是卖老药（麻醉、营养液、中成药）维持现金流，二是砸钱做创新抗癌药。核心资产是一款叫**宜泽康**的双特异性ADC，已经在中国获批上市，还跟跨国药企BMS签了总额最高84亿美元的授权合作【招股书 p.19】。另一款核心产品**T-Bren**（HER2 ADC）正在做III期临床【招股书 p.15】。

## 一、核心管线与产品

### 1. 宜泽康（Izalontamab brengitecan，伦康依隆妥单抗）——核心产品

| 项目 | 内容 |
|------|------|
| 靶点 | EGFR × HER3（双特异性抗体ADC）【招股书 p.10】 |
| 定位 | 全球首款且唯一获批上市的双特异性抗体ADC【招股书 p.10】 |
| 技术平台 | HIRE-ADC【招股书 p.11】 |
| 已获批适应症 | 鼻咽癌后线治疗（2026年6月获批）、食管鳞癌二线治疗（2026年7月获批）【招股书 p.10】 |
| NDA已受理 | 三阴性乳腺癌（2026年6月获药审中心受理）【招股书 p.14】 |
| 核心专利保护期 | 预计覆盖至2042年11月【招股书 p.12】 |

**关键数据（已公布临床结果）：**

- **EGFR突变型NSCLC（I期，2023年ASCO）**：ORR 63.2%，DCR 89.5%【招股书 p.13】
- **EGFR突变型NSCLC一线（2025年WCLC）**：联合奥希替尼，ORR 100%，DCR 100%，12个月PFS率92.1%，12个月OS率94.8%【招股书 p.13】
- **EGFR突变型NSCLC二线（2025年WCLC）**：单药mPFS 12.5个月，18个月OS率69.2%【招股书 p.13】
- **鼻咽癌III期（2025年ESMO，NCT06118333）**：ORR 54.6% vs 化疗27.0%；mPFS 8.38个月 vs 4.34个月【招股书 p.13】
- **广泛期小细胞肺癌一线联合（2026年ELCC）**：联合斯鲁利单抗，ORR 88.3%，经确认ORR 77.9%，mPFS 8.2个月，12个月OS率80.8%【招股书 p.14】
- **三阴性乳腺癌III期（2026年ASCO，PANKU-Breast02）**：mOS 15.9 vs 12.5个月（HR=0.60）；mPFS 8.5 vs 3.1个月（HR=0.29）【招股书 p.14】
- **食管鳞癌III期（2026年ASCO，PANKU-Esophagus01）**：mOS 9.8 vs 7.2个月（HR=0.64）；mPFS 4.2 vs 2.0个月（HR=0.50）；ORR 35.3% vs 13.1%【招股书 p.14】

**与BMS的合作：**

- 2023年12月11日签约，2024年2月8日生效【招股书 p.19】
- 已收到：首付款8亿美元 + 首个临床里程碑2.5亿美元【招股书 p.15】
- 潜在总对价：最高84亿美元（含首付款、近期付款及开发/监管/销售里程碑）【招股书 p.19】
- 分工：我们保留中国内地独家开发、商业化及制造权；BMS拥有全球其他地区独家许可【招股书 p.14】

### 2. T-Bren（trastuzumab brengitecan）——核心产品

| 项目 | 内容 |
|------|------|
| 靶点 | HER2（ADC）【招股书 p.15】 |
| 有效载荷 | 自主研发的拓扑异构酶I抑制剂Ed-04【招股书 p.15】 |
| 定位 | 具备同类最佳潜力的HER2 ADC【招股书 p.15】 |
| 临床阶段 | 8项III期、1项II/III期注册试验、3项II期、3项I/II期、3项I期（共18项）【招股书 p.15】 |

**关键数据：**

- **胃癌/胃食管结合部腺癌（2025年ESMO）**：ORR 55.3%，经确认ORR 47.4%，DCR 92.1%，mPFS 8.4个月【招股书 p.15】
- **HER2突变NSCLC（2025年ESMO）**：经确认ORR 56.9%，6个月PFS率88.7%【招股书 p.15】
- **铂耐药复发卵巢癌（2026年ASCO）**：经确认ORR 52.5%，9个月PFS率54.7%【招股书 p.15】
- **HER2+乳腺癌一线联合（2026年ASCO）**：联合帕妥珠单抗，1年PFS率90.8%，1年OS率95%，经确认ORR 87.5%【招股书 p.15】
